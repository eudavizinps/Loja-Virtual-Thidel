## Sobre o projeto

A página apresenta a marca Thidel, suas coleções e uma seleção de peças de moda masculina. O layout foi pensado para destacar fotografia, tipografia e navegação simples em telas grandes e pequenas.

## Tecnologias

- Next.js 14 e React 18
- TypeScript
- Tailwind CSS
- Cloudflare Pages para hospedagem

## Executar localmente

Requer Node.js e npm.

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Publicação

O projeto usa exportação estática do Next.js. `npm run build` gera os arquivos na pasta `out`. A Cloudflare Pages acompanha a branch `main` e publica novos commits automaticamente.
